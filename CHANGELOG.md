# Changelog
## 0.4.0 - 2026-10-12
- First Lite release, derived from Godot Survival Core 0.4.0. Includes SurvivalStats, DayNightClock, Inventory, RecipeBook and Gatherable, a small data-driven example scene and a strict headless suite.
- CC0 sprite demo scene (examples/demo.tscn, main scene) with F5/F9 save/load and a minimal Ninja Adventure + Kenney asset subset with licence files.
